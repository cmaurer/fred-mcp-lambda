# fred-mcp-lambda

A remote MCP server for [FRED](https://fred.stlouisfed.org) (Federal Reserve Economic Data), running on AWS Lambda behind a public function URL. It lets claude.ai — including scheduled tasks that run in Anthropic's cloud — use FRED without your computer being on.

## What's deployed

| Item | Value |
|---|---|
| AWS account / region | 381491912865 / us-east-1 |
| CloudFormation stack | `fred-mcp` |
| Function | `fred-mcp` (Python 3.13, arm64, 256 MB, 60 s) |
| Endpoint | `https://us23ygry4whchtgg5breouy6j40nkhaj.lambda-url.us-east-1.on.aws/` |
| Secret | `fred-mcp/config` |
| Logs | `/aws/lambda/fred-mcp` (30-day retention) |
| claude.ai connector | `FRED` (custom connector, "No sign in", `Authorization: Bearer <token>` header) |

## How it works

- **Transport:** MCP streamable HTTP in stateless mode. Each request is one POST carrying a JSON-RPC message, answered with plain JSON. No SSE, no sessions — a natural fit for Lambda.
- **Dependencies:** none beyond the Python standard library and boto3 (bundled in the Lambda runtime), so there is no build step and cold starts are fast.
- **Auth:** every request must send `Authorization: Bearer <token>`. Anything else gets a 401. `/.well-known/*` returns 404 so OAuth discovery probes fail fast.
- **Secret** (`fred-mcp/config`, JSON):
  - `fred_api_key` — your FRED API key, set by hand.
  - `bearer_token` — the endpoint's password, generated by CloudFormation. Never edit it by hand; it's what claude.ai sends.
  - The function caches the secret for 5 minutes, so changes take up to 5 minutes to apply.
- **IAM:** the function role can write its own log group and read that one secret. Nothing else.

## Tools

`fred_search_series`, `fred_get_series`, `fred_get_observations`, `fred_get_series_tags`, `fred_get_series_updates`, `fred_search_by_tags`, `fred_get_category`, `fred_get_category_series`, `fred_list_releases`, `fred_get_release_series`

`fred_get_observations` defaults to the 120 most recent points, newest first; pass `sort_order: "asc"` with `observation_start` for history, and `units: "pc1"` for year-over-year % change. Missing values come back as `null`.

A non-tool method, `fred/source_sha256`, returns the SHA-256 of the deployed source (stripped of surrounding whitespace) so you can confirm what's running matches this repo.

## Deploy changes

```bash
python3 build_template.py
aws cloudformation deploy --region us-east-1 --stack-name fred-mcp \
  --template-file template.json --capabilities CAPABILITY_IAM
```

The secret's values survive updates (CloudFormation only regenerates the token if the secret resource is replaced).

## Check the live endpoint

```bash
URL=https://us23ygry4whchtgg5breouy6j40nkhaj.lambda-url.us-east-1.on.aws/
TOKEN=$(aws secretsmanager get-secret-value --region us-east-1 --secret-id fred-mcp/config \
  --query SecretString --output text | python3 -c 'import json,sys;print(json.load(sys.stdin)["bearer_token"])')

# expect 401
curl -s -o /dev/null -w '%{http_code}\n' "$URL" -H 'Content-Type: application/json' -d '{}'

# compare with: python3 -c "import hashlib;print(hashlib.sha256(open('src/app.py').read().strip().encode()).hexdigest())"
curl -s "$URL" -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"fred/source_sha256"}'; echo

# live data
curl -s "$URL" -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"fred_get_observations","arguments":{"series_id":"BAMLH0A0HYM2","limit":3}}}'; echo
```

## Rotate the bearer token

1. Put a new random value in `bearer_token` (e.g. `openssl rand -hex 24`), keeping `fred_api_key` unchanged.
2. Update the `Authorization` header on the claude.ai FRED connector.
3. Allow up to 5 minutes for the function's cached copy to expire.

## Tear down

```bash
aws cloudformation delete-stack --region us-east-1 --stack-name fred-mcp
```

Then remove the FRED connector in claude.ai. If you redeploy soon after, check that the old `fred-mcp/config` secret isn't still pending deletion (Secrets Manager can hold deleted secrets in a recovery window), since the name must be free.
